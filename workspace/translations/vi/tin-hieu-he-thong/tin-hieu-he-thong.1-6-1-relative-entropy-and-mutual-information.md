Cho đến nay trong phần này, chúng tôi đã giới thiệu một số khái niệm từ lý thuyết thông tin, bao gồm khái niệm chính về entropy. Bây giờ chúng tôi bắt đầu liên hệ các ý tưởng này với nhận dạng mẫu. Xem xét một số phân phối chưa biết $p ( \mathbf { x } )$ , và giả sử rằng chúng tôi đã mô hình hóa điều này bằng cách sử dụng phân phối xấp xỉ $q ( \mathbf { x } )$ . Nếu chúng tôi sử dụng $q ( \mathbf { x } )$ để xây dựng một sơ đồ mã hóa nhằm mục đích truyền các giá trị của x cho người nhận, thì lượng thông tin bổ sung trung bình (tính bằng nats) cần thiết để chỉ định giá trị của x (giả sử chúng tôi chọn một sơ đồ mã hóa hiệu quả) do sử dụng $q ( \mathbf { x } )$ thay vì phân phối thực $p ( \mathbf { x } )$ được cho bởi

$$\begin{array}{r c l} \mathrm{KL} (p \| q) & = & - \int p (\mathbf {x}) \ln q (\mathbf {x})   \mathrm{d} \mathbf {x} - \left(- \int p (\mathbf {x}) \ln p (\mathbf {x})   \mathrm{d} \mathbf {x}\right) \\ & = & - \int p (\mathbf {x}) \ln \left\{\frac {q (\mathbf {x})}{p (\mathbf {x})} \right\}   \mathrm{d} \mathbf {x}. \end{array}\tag{1.113}$$

Đây được gọi là entropy tương đối hoặc divergence Kullback-Leibler, hoặc divergence KL (Kullback and Leibler, 1951), giữa các phân phối $p ( \mathbf { x } )$ và $q ( \mathbf { x } )$ . Lưu ý rằng nó không phải là một đại lượng đối xứng, tức là $\mathrm { K L } ( p \| q ) \not \equiv \mathrm { K L } ( q \| p )$

Bây giờ chúng tôi chỉ ra rằng divergence Kullback-Leibler thỏa mãn KL $( p \| q ) \geqslant 0$ với đẳng thức khi và chỉ khi $p ( \mathbf { x } ) = q ( \mathbf { x } )$ . Để làm điều này, trước tiên chúng tôi giới thiệu khái niệm về các hàm lồi. Một hàm $f ( x )$ được gọi là lồi nếu nó có tính chất là mọi dây cung nằm trên hoặc phía trên hàm, như được hiển thị trong Hình 1.31. Bất kỳ giá trị nào của x trong khoảng từ $x = a$ đến $x = b$ có thể được viết dưới dạng $\lambda a + ( 1 - \lambda ) b$ trong đó $0 \leqslant \lambda \leqslant 1$ . Điểm tương ứng trên dây cung được cho bởi $\lambda f ( a ) + ( 1 - \lambda ) f ( b )$
