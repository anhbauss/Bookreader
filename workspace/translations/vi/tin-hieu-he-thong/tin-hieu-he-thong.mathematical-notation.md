Tôi đã cố gắng giữ nội dung toán học của cuốn sách ở mức tối thiểu cần thiết để đạt được sự hiểu biết đúng đắn về lĩnh vực này. Tuy nhiên, mức tối thiểu này khác không, và cần nhấn mạnh rằng sự nắm vững tốt về phép tính, đại số tuyến tính và lý thuyết xác suất là cần thiết để hiểu rõ các kỹ thuật nhận dạng mẫu và học máy hiện đại. Dù vậy, trọng tâm của cuốn sách này là truyền đạt các khái niệm cơ bản chứ không phải về độ chặt chẽ về mặt toán học.

Tôi đã cố gắng sử dụng ký hiệu nhất quán xuyên suốt cuốn sách, mặc dù đôi khi điều này có nghĩa là lệch khỏi một số quy ước được sử dụng trong tài liệu nghiên cứu tương ứng. Các vectơ được ký hiệu bằng các chữ cái La Mã đậm chữ thường như **x**, và tất cả các vectơ được giả định là vectơ cột. Chỉ số trên T biểu thị chuyển vị của ma trận hoặc vectơ, sao cho $\mathbf { x } ^ { \mathrm { { T } } }$ sẽ là vectơ hàng. Các chữ cái La Mã đậm chữ hoa, chẳng hạn như **M**, biểu thị các ma trận. Ký hiệu $( w _ { 1 } , \ldots , w _ { M } )$ biểu thị một vectơ hàng có M phần tử, trong khi vectơ cột tương ứng được viết là $\mathbf { w } = ( w _ { 1 } , \hdots , w _ { M } ) ^ { \mathrm { T } }$

Ký hiệu $[ a , b ]$ được sử dụng để biểu thị khoảng đóng từ a đến $b ,$ tức là khoảng bao gồm các giá trị a và b, trong khi $( a , b )$ biểu thị khoảng mở tương ứng, tức là khoảng loại trừ a và b. Tương tự, $[ a , b )$ biểu thị một khoảng bao gồm $a$ nhưng loại trừ b. Tuy nhiên, phần lớn thời gian, không cần phải chú ý nhiều đến những tinh tế như việc các điểm cuối của một khoảng có được bao gồm hay không.

Ma trận đơn vị $M \times M$ (còn được gọi là ma trận đơn vị) được ký hiệu ${ \mathbf { I } } _ { M }$ sẽ được viết tắt thành I khi không có sự mơ hồ về thứ nguyên của nó. Nó có các phần tử $I _ { i j }$ bằng 1 nếu $i = j$ và $0 \mathrm { i f } i \neq j$

Một phiếm hàm được ký hiệu $f [ y ]$ trong đó $y ( x )$ là một hàm nào đó. Khái niệm về phiếm hàm được thảo luận trong Phụ lục D.

Ký hiệu $g ( x ) = O ( f ( x ) )$ biểu thị rằng $| f ( x ) / g ( x ) |$ bị chặn khi $x \to \infty$ Ví dụ, nếu $g ( x ) = 3 x ^ { 2 } + 2$ , thì $g ( x ) = O ( x ^ { 2 } )$

Kỳ vọng của hàm $f ( x , y )$ với biến ngẫu nhiên x được ký hiệu bởi $\mathbb { E } _ { x } [ f ( x , y ) ]$ . Trong những tình huống không có sự mơ hồ về biến nào đang được trung bình hóa, điều này sẽ được đơn giản hóa bằng cách bỏ đi hậu tố, ví dụ

E[x]. Nếu phân bố của x được điều kiện hóa bởi một biến khác z, thì kỳ vọng có điều kiện tương ứng sẽ được viết $\mathbb { E } _ { x } [ f ( x ) | z ]$ . Tương tự, phương sai được ký hiệu var $[ f ( x ) ]$ ], và đối với các biến vectơ, hiệp phương sai được viết $\operatorname { c o v } [ \mathbf { x } , \mathbf { y } ]$ . Chúng tôi cũng sẽ sử dụng $\mathrm { c o v } [ \mathbf { x } ]$ như một ký hiệu viết tắt cho $\operatorname { c o v } [ \mathbf { x } , \mathbf { x } ]$ . Các khái niệm về kỳ vọng và hiệp phương sai được giới thiệu trong Phần 1.2.2.

Nếu chúng ta có N giá trị $\mathbf { x } _ { 1 } , \ldots , \mathbf { x } _ { N }$ của vectơ D-chiều $\mathbf x = ( x _ { 1 } , \dots , x _ { D } ) ^ { \mathrm T }$ chúng ta có thể kết hợp các quan sát vào ma trận dữ liệu X trong đó hàng $n ^ { \mathrm { t h } }$ của X tương ứng với vectơ hàng ${ \bf x } _ { n } ^ { \mathrm { T } }$ . Do đó phần tử $n , i$ của X tương ứng với phần tử $i ^ { \mathrm { t h } }$ của quan sát $n ^ { \mathrm { t h } }$ ${ \bf x } _ { n }$ . Đối với trường hợp các biến một chiều, chúng tôi sẽ ký hiệu ma trận này bằng x, đây là vectơ cột có phần tử $n ^ { \mathrm { t h } }$ là $x _ { n }$ Lưu ý rằng x (có thứ nguyên N) sử dụng kiểu chữ khác để phân biệt nó với x (có thứ nguyên D).
