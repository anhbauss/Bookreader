Giả sử rằng mục tiêu của chúng ta là đơn giản chỉ là thực hiện càng ít sai phân loại càng tốt. Chúng ta cần một quy tắc gán mỗi giá trị của x cho một trong các lớp có sẵn. Quy tắc như vậy sẽ chia không gian đầu vào thành các vùng $\mathcal { R } _ { k }$ gọi là các vùng quyết định, một vùng cho mỗi lớp, sao cho tất cả các điểm trong $\mathcal { R } _ { k }$ được gán cho lớp $\mathcal { C } _ { k }$. Các ranh giới giữa các vùng quyết định được gọi là các ranh giới quyết định hoặc các bề mặt quyết định. Lưu ý rằng mỗi vùng quyết định không cần phải liên tục mà có thể bao gồm một số vùng rời rạc. Chúng ta sẽ gặp các ví dụ về các ranh giới quyết định và các vùng quyết định trong các chương sau. Để tìm quy tắc quyết định tối ưu, trước tiên hãy xem xét trường hợp hai lớp, như trong bài toán ung thư chẳng hạn. Một lỗi xảy ra khi một vectơ đầu vào thuộc lớp $\mathcal { C } _ { 1 }$ được gán cho lớp $\mathcal { C } _ { 2 }$ hoặc ngược lại. Xác suất điều này xảy ra được cho bởi

\begin{array}{r c l} p (\text {mistake}) & = & p (\mathbf {x} \in \mathcal {R} _ {1}, \mathcal {C} _ {2}) + p (\mathbf {x} \in \mathcal {R} _ {2}, \mathcal {C} _ {1}) \\ & = & \int_ {\mathcal {R} _ {1}} p (\mathbf {x}, \mathcal {C} _ {2})   \mathrm{d} \mathbf {x} + \int_ {\mathcal {R} _ {2}} p (\mathbf {x}, \mathcal {C} _ {1})   \mathrm{d} \mathbf {x}. \end{array}\tag{1.78}

Chúng ta có tự do lựa chọn quy tắc quyết định gán mỗi điểm x cho một trong hai lớp. Rõ ràng để cực tiểu hóa p(mistake) chúng ta nên sắp xếp sao cho mỗi x được gán cho lớp bất kỳ có giá trị nhỏ hơn của hàm tích phân trong (1.78). Do đó, nếu $p ( \mathbf { x } , \mathcal { C } _ { 1 } ) >$ $p ( \mathbf { x } , \mathcal { C } _ { 2 } )$ cho một giá trị nhất định của $\mathbf { x } ,$ thì chúng ta nên gán x đó cho lớp $\mathcal { C } _ { 1 }$. Từ quy tắc tích của xác suất chúng ta có $p ( \mathbf { x } , \mathcal { C } _ { k } ) = p ( \mathcal { C } _ { k } | \mathbf { x } ) p ( \mathbf { x } )$. Vì thừa số $p ( \mathbf { x } )$ là chung cho cả hai số hạng, chúng ta có thể phát biểu lại kết quả này bằng cách nói rằng xác suất cực tiểu của việc mắc lỗi đạt được nếu mỗi giá trị của x được gán cho lớp mà xác suất hậu nghiệm $p ( \mathcal { C } _ { k } | \mathbf { x } )$ là lớn nhất. Kết quả này được minh họa cho hai lớp và một biến đầu vào x trong Hình 1.24.

Minh họa sơ đồ của các xác suất chung $p ( x , \mathcal { C } _ { k } )$ cho mỗi hai lớp được vẽ dựa trên $x ,$ , cùng với ranh giới quyết định $x = { \widehat { x } }$. Các giá trị của $x \geqslant { \widehat { x } }$ được phân loại là lớp $\mathcal { C } _ { 2 }$ và do đó thuộc vùng quyết định $\mathcal { R } _ { 2 }$, trong khi các điểm $x < { \widehat { x } }$ được phân loại là $\mathcal { C } _ { 1 }$ và thuộc $\mathcal { R } _ { 1 }$. Các lỗi phát sinh từ các vùng màu xanh lam, xanh lục và đỏ, sao cho đối với $x < { \widehat { x } }$ các lỗi là do các điểm từ lớp $\mathcal { C } _ { 2 }$ bị phân loại sai thành $\mathcal { C } _ { 1 }$ (được biểu thị bằng tổng các vùng đỏ và xanh lục), và ngược lại đối với các điểm trong vùng $x \geqslant { \widehat { x } }$ các lỗi là do các điểm từ lớp $\mathcal { C } _ { 1 }$ bị phân loại sai thành $\mathcal { C } _ { 2 }$ (được biểu thị bằng vùng màu xanh lam). Khi chúng ta thay đổi vị trí $\widehat { x }$ của ranh giới quyết định, các diện tích kết hợp của các vùng màu xanh lam và xanh lục vẫn không đổi, trong khi kích thước của vùng đỏ thay đổi. Lựa chọn tối ưu cho $\widehat { x }$ là nơi các đường cong cho $p ( x , \mathcal { C } _ { 1 } )$ và $p ( x , \mathcal { C } _ { 2 } )$ cắt nhau, tương ứng với $\widehat { x } = x _ { 0 }$, bởi vì trong trường hợp này vùng đỏ biến mất. Điều này tương đương với quy tắc quyết định tỷ lệ sai phân loại cực tiểu, gán mỗi giá trị của $x$ cho lớp có xác suất hậu nghiệm $p ( \mathcal { C } _ { k } | x )$ cao hơn.

Đối với trường hợp tổng quát hơn của K lớp, thật sự dễ dàng hơn một chút khi cực đại hóa xác suất của việc được phân loại đúng, được cho bởi

\begin{array}{r c l} p (\text { correct }) & = & \sum_ {k = 1} ^ {K} p (\mathbf {x} \in \mathcal {R} _ {k}, \mathcal {C} _ {k}) \\ & = & \sum_ {k = 1} ^ {K} \int_ {\mathcal {R} _ {k}} p (\mathbf {x}, \mathcal {C} _ {k})   \mathrm{d} \mathbf {x} \end{array}\tag{1.79}

được cực đại hóa khi các vùng $\mathcal { R } _ { k }$ được chọn sao cho mỗi x được gán cho lớp mà $p ( \mathbf { x } , \mathcal { C } _ { k } )$ là lớn nhất. Lần nữa, sử dụng quy tắc tích $p ( \mathbf { x } , \mathcal { C } _ { k } ) =$ $p ( \mathcal { C } _ { k } | \mathbf { x } ) p ( \mathbf { x } )$ , và lưu ý rằng thừa số $p ( \mathbf { x } )$ là chung cho tất cả các số hạng, chúng ta thấy rằng mỗi x nên được gán cho lớp có xác suất hậu nghiệm $p ( \mathcal { C } _ { k } \vert \mathbf { x } )$ lớn nhất.
