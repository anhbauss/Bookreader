CHAPTER I · CONTINUOUS-TIME SIGNALS

Signals and Systems

A signal is a function of one or more variables that conveys information about the behavior or nature of a physical phenomenon. Although mathematical models can appear abstract, they are a precise way to describe the relationships that persist through change.

The central aim of a system representation is to reveal what can be predicted from what is known. A system accepts a signal as an input and transforms it into another signal, called the output. The particular form of this transformation determines the properties that matter to a reader.

For many problems, the first useful question is whether the response depends only on the present input or also on inputs that occurred earlier. This distinction separates memoryless systems from systems with memory and shapes the tools available for analysis.

Linearity gives a second powerful simplification. When a system is linear, the response to a weighted sum of signals is the corresponding weighted sum of the responses. This property allows complicated signals to be understood from smaller, familiar pieces.

A third property, time invariance, asks whether delaying the input merely delays the output by the same amount. Together, linearity and time invariance create a framework in which convolution becomes a natural description rather than a rule to memorize.
